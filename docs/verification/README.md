# Проверки и сохранённые результаты

Датированные результаты относятся к указанным ревизиям и окружениям.
Они не подтверждают текущий HEAD или production.

- [Синхронизация staging 06.10.2026](staging-sync-2026-10-06.md) —
  происхождение исходников, проверки пяти проектов и ограничения rollout.
- [Приёмка Activity 12.09.2026](stages1-9-2026-09-12/README.md) —
  выполненные live-проверки и оставшиеся эксплуатационные пункты.
- [Проверки Activity CI](activity-ci.md) — воспроизводимые команды и gates.
- [Измерения чтения](stage6-2026-09-08/rel-02.md) и
  [повторный аудит нагрузки](stage6-2026-09-08/fixes/README.md) —
  evidence, используемое ADR-0019.
- [Совместимость owner-миграций 11.09.2026](stage8-2026-09-08/migrations-compat.md) —
  историческая матрица для backup/restore; новые миграции сверять с кодом.

Промежуточные отчёты этапов и исправлений удалены из рабочего дерева.
Их пути в сохранённых результатах обозначают документы из истории Git.
Текущие инструкции находятся в [runbooks](../runbooks/README.md),
контракты — в [specs](../specs/README.md).
