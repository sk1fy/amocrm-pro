# Historical verification reports

Отчёты в этом каталоге фиксируют результат конкретного прогона на указанной
ревизии. Они не подтверждают состояние текущего `HEAD`; актуальное поведение
нужно проверять тестами и CI.

В репозитории остаются только Markdown-резюме с командами, результатами и
известными ограничениями. Сырые stdout/stderr, временные JSON-снимки,
checksum-манифесты и патчи удалены из рабочего дерева: они быстро устаревают,
дублируют Git/CI и раньше занимали большую часть `docs`. Имена таких артефактов
в старых отчётах сохранены как обычный текст для поиска в истории Git.

Для текущей документации используйте:

- [`../architecture.md`](../architecture.md) — фактическая архитектура;
- [`../runbooks/`](../runbooks/) — эксплуатационные инструкции;
- [`../specs/`](../specs/) — продуктовые и интеграционные контракты;
- [`../project-memory/`](../project-memory/) — устойчивый контекст, roadmap и дефекты.
