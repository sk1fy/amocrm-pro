# Исправления ревью этапа 5

сборочные производные Backend Tester 2. Go, owner migrations и wire-контракты

## Результат

1. Справочник сотрудников и отделов хранится отдельно от отфильтрованного
   ответа панели. Возврат из журнала сотрудника восстанавливает прежний
   именованный/ручной выбор и отдел. Сайт также сохраняет справочник для формы.
2. **По прямому указанию владельца конец пресетов — 23:59:50**, а не
   23:59:59. Оба клиента сохраняют секунды в datetime-local, используют шаг
   1 секунду и отправляют тот же включительный Unix timestamp при обновлении.
3. Временная ошибка карточки больше не кешируется как окончательная
   недоступность объекта. После 503 можно закрыть и открыть карточку для
   повтора. 404 остаётся недоступностью до следующего обновления панели.
4. Кеш карточек действует в пределах одного чтения панели и её страниц.
   Обновление инвалидирует кеш и повторно загружает открытые карточки,
   позволяя увидеть переход enrichment pending → ready. Запоздалый ответ
   старой карточки не перезаписывает результат нового чтения.
