# Исправления ревью этапа 4

Дата: 8 сентября 2026 года. Проверено рабочее дерево с реализацией этапов
1–4. Runtime и production не менялись. Миграций и изменений wire-контрактов
для этих исправлений нет.

## Изменения

1. **Выбранные и неизвестные авторы.** Для `user_ids` вместе с
   `include_unknown_authors` Activity получает полный доступный directory,
   использует его ID для определения неизвестных авторов, затем отдельно
   фильтрует отображаемых сотрудников. Действующий невыбранный сотрудник
   больше не попадает в журнал, сводки и totals как неизвестный. Отделы
   по-прежнему исключают unknown. Полный directory ограничен прежними
   100 сотрудниками; превышение возвращает ошибку. Без unknown явный
   выбор продолжает использовать отфильтрованный Gateway-запрос.
2. **Повторяющийся час.** Validation и owner используют один генератор
   временных границ в serviceapi. Границы передаются в SQL как абсолютные
   timestamps; `width_bucket` распределяет события по ним, сохраняя общий
   WHERE и ограничение числа корзин. SQL больше не преобразует локальный
   повторяющийся час обратно в неоднозначный timestamp.
3. **Автоматический масштаб.** `auto` проверяет фактическое число часовых
   корзин вместе с частичными краями; при >48 переключается на дни.
   Явный `hour` сохраняет ограничение и возвращает ошибку при превышении.
4. **Названия сущностей.** `EntityLabel` проверяет kind=entity и пару
   нормализованный тип/ID. Одноимённые числовые ID разных типов не смешиваются;
   неподходящее или не имеющее типа имя не подставляется вместо fallback.

## Проверки

До исправления все четыре сценария воспроизведены:
[исходные FAIL](fixes/review-failures.txt).

Целевой прогон serviceapi/activity/crmevents с отдельными PostgreSQL owner DB
и `-race -count=1 -p 1`: **81 PASS, 0 SKIP, 0 FAIL**.
[Лог](fixes/targeted-tests.txt).

Четыре новых регрессионных теста проверяют:

- выбранных, неизвестных, удалённых авторов и фильтр отдела через Activity
  и реальный SQL; неизменность totals и состава сотрудников при пагинации;
- первый, второй и оба осенних повторяющихся часа, весенний пропуск часа,
  25-часовой день и частичные корзины в зоне UTC+05:30;
- границы auto: ровные/неполные 48 часов и включительный конечный timestamp;
- совпадающие ID контакта, сделки и поля, singular/plural типы и отсутствие
  пригодного имени.


UI 5 PASS, 0 SKIP**. Проверены owner PostgreSQL, mTLS, реальные процессы,
аварийные перезапуски, embedded/gRPC и общий бюджет. Необязательная проверка
с прежним API-бинарём пропущена: `COMPONENT_PROCESS_PREVIOUS_API_BINARY`
не задан. Тестовые контейнеры и volumes полного gate удалены штатным cleanup.
