# Проверка Go-зависимостей

Запустить `make vulncheck` в Core и Admin. Команда выполняет govulncheck
в Docker, использует текущую официальную базу Go и возвращает ненулевой
код при достижимой уязвимости. Сетевой/инструментальный сбой также
не считается успешной проверкой.

При находке проверить установленную версию, исправленный диапазон и
цепочку вызовов. После обновления выполнить обычные Docker-проверки
проекта; для gRPC дополнительно `make activity-ci`. Сборку и доставку
образов в целевую среду проверять отдельно по ревизии образа.

Основание: [ADR-0030](../adr/0030-go-vulnerability-check.md).
