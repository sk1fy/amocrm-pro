# Отдельное право на каталог виджетов

## Контекст

Доступ к каталогу выдаётся отдельно от чтения клиентских карточек.

## Решение

Platform принимает `catalog.read` для списка и карточки продукта.
Для прежнего Admin BFF на этих маршрутах принимается `clients.read`.
Новый BFF проверяет именно `catalog.read` перед вызовом Platform.
Сводка с данными аккаунтов сохраняет проверки `clients.read`
и `stats.read`.

## Последствия

Platform должен понимать новый grant до запуска Admin API,
который передаёт его в контексте акторов. Изменения схемы данных
Platform не требуются.
