# Подписи событий кабинета менеджеров

## Контекст

Чтобы читать ленту по аккаунтам и виджетам, менеджеру нужны подписи.
Platform уже хранит идентичности аккаунтов и каталог виджетов.
Курсорный снимок ленты фиксирует состав и порядок событий.

## Решение

Для выдаваемых событий Platform добавляет необязательные
`account_subdomain` и `product_display_name` при `clients.read`.
Подписи берутся из текущих записей идентичности и каталога.
Отсутствие поддомена, каталожного продукта или разрешённого перехода
обозначается пропуском соответствующего поля. Лента и история
используют одинаковое правило.

## Последствия

Каталожные подписи могут измениться между страницами. ID и порядок
курсора остаются привязаны к снимку. Приватные данные источника
и новые виды событий не добавляются. Admin BFF должен принять
расширенную схему до выкладки производителя полей.
