# Суточная сверка аккаунтов

Platform планирует чтение установок, реквизитов и пользователей по аккаунту. Слот компонента хранит срок очередной проверки, время попытки, последнего успеха и результат. Очередь общая для автоматических и ручных запросов. Время суток распределено по стабильному хешу аккаунта UTC.

Core предоставляет Platform постраничный список одобренных установок по mTLS. Для исторической установки оператор подтверждает точное соответствие аккаунта, интеграции, установки и продукта. Такое разрешение даёт право читать реквизиты и пользователей. Выдача доступа к виджету, пробный срок, события установки и создание сделки имеют отдельные основания.

После получения всех страниц Platform публикует наблюдение одной транзакцией. Оно дополняет каталог и позволяет видеть изменение авторизации. При наличии более нового события установки используется его состояние. Для обновления пользователей достаточно одной доступной установки. Core проверяет полномочия до и после обращения к amoCRM.
