# ADR 0053. Метрики каталога виджетов

## Контекст

Каталогу нужны сводка, график по каждому продукту и очередь установок
с потерянной авторизацией. Доступ к метрикам выдаётся отдельно от
доступа к карточке каталога. Существующие «активные доступы» описывают
права на продукт с учётом сроков.

## Решение

Запрос каталога с `overview=true` требует `clients.read` и `stats.read`.
Сводка и очередь охватывают весь каталог. Поиск, фильтры и сортировка
применяются перед пагинацией. Строки, сводка и очередь читаются в одной
транзакции. Курсор привязан к дате, правам, фильтрам, ревизии каталога
и хешу метрик. При изменении метрик нужно начать с первой страницы.

График считает подтверждённые эпизоды, включая переустановки,
по текущему и 11 предыдущим месяцам в часовом поясе Platform.
Отдельный счётчик использует скользящие 30 суток. «Стоят сейчас»
считает текущие пары «аккаунт и продукт» по справочнику установок,
включая импортированные. Доля оставшихся использует только
подтверждённые эпизоды из периода графика.

Доля записанных активаций считается по подтверждённым эпизодам
каждой интеграции начиная с даты установки первого эпизода с
контактом активации. Пока такого сигнала нет, доля неизвестна.
Порог 90% относится к записанным событиям. Сводка взвешена по
числу эпизодов, для которых рассчитывается доля.

Очередь ограничена 100 записями и показывает общий счётчик. В неё
входят текущие подтверждённые установки с `reauth_required`.
Дата берётся из соответствующего события смены авторизации.
Для публично доступных виджетов проверяются ссылки с установленными
названиями «Установка», «Установить», «Ссылка на установку»,
«Инструкция» и «Документация». Сверка регистронезависимая.

## Отклонённые варианты

Запрос метрик по одному продукту на строку сделал бы сводку и
сортировку зависимыми от страницы. Считать действующие права
числом установок нельзя из-за тарифов и сроков.

## Последствия

Базовый список и карточка сохраняют прежний контракт. При выкладке
сначала обновляется BFF, затем Platform, затем интерфейс. Миграция
для чтения метрик не требуется. Подписка, версия релиза, метки
публикации и ручная проверка связи требуют отдельных источников
или прав. Очередь остаётся доступной для просмотра.
