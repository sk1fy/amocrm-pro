# Пакетная подписка аккаунта
## Контекст
Аккаунт может получить доступ сразу к нескольким категориям виджетов.
Установка, OAuth, активация и индивидуальный срок имеют собственный цикл.
## Решение
Platform хранит версии пакета по аккаунту. Каждое изменение содержит
тип, дату окончания, лимит, сделку и ссылку на команду менеджера.
Команда требует clients.renew, ключ идемпотентности и версию профиля.
Выдача TOP и смена классификации происходят в одной транзакции.
Дата включительна по Москве. Для проверки лимита используется последний
успешно полученный снимок активных пользователей. Если снимка ещё нет,
пакет ожидает данных. Ошибка источника сохраняет последний результат.
## Последствия
Пакет охватывает текущие и будущие установки подходящей категории.
Сервис проверяет авторизацию установки как прежде. Действующий пакет
участвует в выборе более позднего срока вместе с индивидуальным сроком.
Версия индивидуального срока по-прежнему используется для его продления.
