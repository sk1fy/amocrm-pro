# 0061. Проверка установки при смене эпизода

## Контекст

Кабинет проверяет первую установку виджета в аккаунте. Переустановка
создаёт отдельный эпизод для истории и не требует новой проверки.

## Решение

Platform переносит автора и время последней отметки в новый эпизод
в транзакции переустановки. Явное снятие отметки сохраняет проверку
открытой. Повторная авторизация обновляет текущий эпизод.

Миграция 000030 восстанавливает отметки текущих переустановок из
предыдущих эпизодов. Команда проверки изменяет текущий эпизод под
блокировкой потока установки. Так операция и переустановка выполняются
последовательно при одновременном запросе.

## Последствия

Очередь читает текущие эпизоды и показывает одну проверку для пары
аккаунт и виджет. История сохраняет закрытые эпизоды и исходные события
проверки. Повтор ранее принятой команды возвращает прежний результат.
Откат удаляет триггер. Восстановленные отметки остаются в базе.
