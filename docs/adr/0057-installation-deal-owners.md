# Назначение ответственного за сделку по установке

Platform хранит в ревизии настройки сделки соответствия групп клиентов и ID сотрудников корпоративной amoCRM. При сохранении менеджер выбирает сотрудника из того же снимка, что и воронка с этапом. В снимке доступны только ID и имена активных сотрудников. До первого обновления снимка список может отсутствовать.

Перед первым запросом создания Platform определяет группу по текущему профилю клиента и проверяет назначение по последнему снимку. Пустое назначение оставляет выбор за amoCRM. Запрет работы исключает создание сделки. Сверка ранее отправленной сделки по маркеру не меняет ответственного.

Миграция 000022 переименовывает классификацию свободных клиентов в существующих профилях. Ключ назначения direct сохраняет смысл после переименования.
