# 0049. Данные и счётчики очереди установок

## Контекст

Кабинет показывает установку и её аккаунт в одной строке. Две вкладки
отображают число записей при одних фильтрах.

## Решение

Platform дополняет строку профилем и наблюдением аккаунта. Поиск по этим
полям работает в том же авторизованном запросе. `summary` и курсор
сохраняют смысл активной выборки. `queue_counts` рассчитывается до отбора
по проверке и сохраняется в JSON существующего снимка.

Каталог читает подтверждённые эпизоды и уже поддержанные импорты Core
из миграции 000012. Проверка по-прежнему меняет только подтверждённый
эпизод. Эта миграция перенесена без изменений из `ed75cea`.

## Последствия

Admin получает поля и обе сводки одним запросом. Старый снимок или
старый Platform может не содержать второй сводки. Недоступные поля
остаются пустыми.
