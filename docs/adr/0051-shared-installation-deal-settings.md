# Общая воронка для сделок по установкам

## Контекст

Раньше обработчик искал настройку по продукту установки. Менеджеры
выбирают одно место для новых сделок по установкам всех виджетов.

## Решение

Platform хранит версии пары «воронка и этап» для активной привязки
корпоративного аккаунта. Запись проверяет текущую версию, привязку и
членство этапа в актуальном полном снимке. Каждая ревизия ссылается на
команду и менеджера. Обработчик берёт последнюю ревизию для текущей
привязки и повторно проверяет наличие этапа перед первым запросом записи.

Core возвращает состояние подключения приватной интеграции
`rakurscrm-manager` по фиксированному маршруту. Ответ для браузера
ограничен origin аккаунта компании и содержит один boolean. OAuth
активация использует существующие маршруты Core.

## Последствия

Менеджер сохраняет общий выбор перед включением обработчика. История
по продуктам сохранена. Сделки с уже отправленным запросом продолжают
сверку по сохранённой метке. После смены привязки применяется только
настройка для новой привязки.
