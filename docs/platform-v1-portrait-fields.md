# Поля портрета для V1

Фильтр POST `/accounts/search` применяет `portrait_filter` вместе с
фильтрами строки запроса. Каждый узел содержит ровно одно поле `condition`,
`and` или `or`. Допускается до трёх уровней и 30 условий. Для продолжения
выдачи передайте те же фильтры и исходное дерево вместе с подписанным
курсором. Итог и порядок сохраняются из первого снимка.

Идентификаторы фиксированных полей вычисляются как UUIDv5 пространства
имён URL от `https://rakurscrm.ru/platform/portrait/<ключ>`. Для заметки
темы используйте `id` из актуального шаблона. Перестановка тем сохраняет
их идентификаторы и заметки. При удалении темы заметка скрывается.
Возвращение той же темы по её UUID снова открывает заметку.

| Поле | UUID | Тип значения |
| --- | --- | --- |
| `niche_id` | `31f2f50b-f168-5fa5-ae3a-edfa6aed7f49` | UUID ниши |
| `site` | `8664fd0c-985d-5946-a00e-d05612934bea` | Строка |
| `rating` | `99a241de-d761-526b-bd53-184170aa88f2` | Целое число |
| `work_types` | `afb433a0-236c-5f7d-857f-022a82e009d1` | Строки |
| `customer_types` | `8818838b-0c99-53ae-9660-7f2abcdebc96` | Строки |

`eq` принимает одно значение. Для типов работы и клиентов он проверяет
вхождение в список. `in` принимает массив из 1–30 значений и ищет хотя
бы одно совпадение. `exists` проверяет наличие значения. Можно передать
`false`, чтобы найти записи с неизвестным значением. `lt` и `gte`
сравнивают рейтинг. Для темы шаблона сравнивается сохранённая строка
заметки. Неизвестный UUID поля и неподдерживаемый тип дают `400`.

У ручных отметок значения `true` и `false` сохраняются отдельно от
неизвестного значения. `manual: null` снимает отметку.

PATCH портрета принимает отдельные поля `company`, список изменяемых
ручных отметок и список заметок по темам. Пропущенные поля сохраняются.
У полей `niche_id`, `site` и `rating` значение `null` очищает поле.
Пустой список типов задаёт известный пустой набор. Пустая заметка темы
очищает её. Дата аудита имеет формат `YYYY-MM-DD` и добавляется один раз.

Чтобы изменить портрет или добавить дату, передайте его `ETag` в
`If-Match`. Для шаблона и ниш используются их собственные версии.
Слияние ниш проверяет версию источника в `If-Match` и версию цели
в `target_version`. Ответ содержит обновлённую целевую нишу.
Курсор списка ниш действует до изменения справочника. При `invalid_cursor`
откройте первую страницу.
